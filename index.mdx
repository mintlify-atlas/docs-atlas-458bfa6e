Firejail is an SUID sandbox program that reduces the risk of security breaches by restricting the running environment of untrusted applications. Written in C with virtually no dependencies, it runs on any Linux computer with a 3.x kernel or newer and can sandbox servers, graphical applications, and even user login sessions.

## How Firejail works

Firejail creates a restricted environment for each sandboxed process by combining multiple Linux kernel security features:

<CardGroup cols={3}>
  <Card title="Linux Namespaces" icon="layer-group">
    Isolates mount, PID, network, UTS, IPC, and user namespaces so sandboxed processes have their own private view of the system.
  </Card>
  <Card title="seccomp-bpf" icon="filter">
    Restricts which system calls a process can make using the kernel's Berkeley Packet Filter, blocking dangerous syscalls at the kernel level.
  </Card>
  <Card title="Capabilities" icon="key">
    Drops Linux capabilities so that even root processes inside the sandbox cannot perform privileged operations on the host system.
  </Card>
</CardGroup>

## Start sandboxing

<Steps>
  <Step title="Install Firejail">
    Install Firejail from your distribution's package manager or build from source. See the [installation guide](/installation) for details.

    ```bash
    sudo apt-get install firejail
    ```
  </Step>
  <Step title="Run an application in a sandbox">
    Prefix any command with `firejail` to sandbox it. Firejail automatically selects an appropriate security profile.

    ```bash
    firejail /usr/bin/firefox
    firejail /usr/bin/vlc
    firejail /usr/bin/transmission-gtk
    ```
  </Step>
  <Step title="Integrate with your desktop">
    Run `sudo firecfg` to integrate Firejail with your desktop environment. All supported applications will automatically launch in a sandbox.

    ```bash
    firecfg --fix-sound
    sudo firecfg
    ```
  </Step>
  <Step title="Monitor active sandboxes">
    List all running sandboxes or use the monitoring tool to watch resource usage.

    ```bash
    firejail --list
    firemon --top
    ```
  </Step>
</Steps>
